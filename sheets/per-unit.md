# 标幺值（Per-unit, p.u.）

> 标幺值是电气量的有名值与同量纲基准值之比，无量纲，用于把不同电压等级的阻抗归到同一基准下比较和计算。

## 核心公式

$$
A_{pu} = \frac{A}{A_B}
$$

三相计算通常只独立选取 $S_B$（三相容量）与 $U_B$（线电压），其余基准由它们导出：

$$
I_B = \frac{S_B}{\sqrt{3}\, U_B},\quad Z_B = \frac{U_B^2}{S_B}
$$

$$
Z_{pu} = \frac{Z}{Z_B} = \frac{Z(\Omega)\, S_B(\mathrm{MVA})}{[U_B(\mathrm{kV})]^2}
$$

换基准（1 为原基准，2 为新基准）：

$$
Z_{pu2} = Z_{pu1}\left(\frac{S_{B2}}{S_{B1}}\right)\left(\frac{U_{B1}}{U_{B2}}\right)^2
$$

百分值与标幺值：$Z_{pu} = Z\%/100$。变压器短路电压在自身额定基准 $S_N$、$U_N$ 下有 $u_{k,pu} = u_k\%/100$。单相电路改用相电压与单相容量时，$Z_B = U_B^2/S_B$ 的形式不变。$S_{pu} = S/S_B = P_{pu} + jQ_{pu}$。

各级基准电压按变压器额定变比选取时，标幺阻抗折算到任一侧数值不变。

## 典型数值 / 量纲

| 量 | 典型值 | 单位 |
|---|---|---|
| 系统功率基准 $S_B$ | 100（配电计算常用 10） | $\mathrm{MVA}$ |
| 电压基准 $U_B$ | 该级额定线电压，如 10.5、121 | $\mathrm{kV}$ |
| 汽轮发电机 $X_d''$ | 0.10–0.25 | p.u.（自身额定） |
| 配电变压器 $u_k$ | 4–6 | % |
| 110–220 kV 变压器 $u_k$ | 10.5–14 | % |
| 架空线电抗 | 0.3–0.4 | $\Omega/\mathrm{km}$ |
| 标幺值 | — | 无量纲（p.u.） |

## 课堂提示

- 只能独立定两个基准，常用 $S_B$ 与 $U_B$；$I_B$、$Z_B$ 必须由它们算出，不能再另设。
- $U_B$ 取线电压时，$S_B$ 必须取三相容量。线电压配单相功率，或相电压配三相功率，阻抗会错 $\sqrt{3}$ 或 3 倍。
- 铭牌上的 $u_k\%$、$X_d\%$ 属于设备自身 $S_N$、$U_N$。系统基准不同时先换基准再相加，不要把百分数直接串加。
- 有名阻抗折算要乘变比的平方；标幺制下只要各级 $U_B$ 按额定变比选取，折算后的标幺阻抗不变。功率因数与阻抗角不是标幺量，换基准时不变。
